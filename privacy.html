Privacy policy

Last updated: October 27, 2026

Gmail MCP is a private tool used only by its owner, with the owner's own Google account.

What it accesses

With the owner's permission, it reads emails in the owner's Gmail account (gmail.readonly) to find verification codes, and it can create drafts (gmail.compose). It does not send email.

How data is used and kept

Email content is used only to carry out the owner's own requests. Access tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
